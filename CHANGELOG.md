# Histórico

## 0.1.0 — 18/11/2026

Primeira adaptação do pacote TubuloesCurtos_Portatil ao ecossistema OpenStruct.

- Interface React/TypeScript com ribbon e organização visual inspirada no ArmaduraStruct.
- Projeto com vários tubulões, parâmetros, ações, furos SPT, portabilidade e recuperação local.
- Núcleo Python preservado, com adaptador validado, API local e IPC desktop.
- Modelo 3D, corte, esforços, sondagens, verificações, mapa D × L, memória HTML e quantitativos.
- Exportação CSV, JSON, HTML e 3D offline; integração TQS original preservada.
- Bloqueio de entradas que o núcleo não implementa integralmente e invalidação de resultados desatualizados.
- Testes de regressão dos três exemplos originais, proteção de entradas, interface e processo empacotado.
- Estrutura Tauri 2 para instaladores Windows e Linux, com geração de ícones a partir de SVG.
